# Pop!_OS 24.04 WSL Base 0.1.1

Version **0.1.1** is the first cold-boot-clean release of the Pop!_OS 24.04 WSL Base.

## Highlights

- Pop!_OS 24.04 LTS / Noble
- x86_64 / amd64
- systemd enabled and running
- English OOBE
- UID/GID 1000 user creation
- Windows interoperability working
- WSLg-compatible base
- Pop!_OS repositories preserved
- no desktop environment or display manager
- zero failed systemd units in the validated clean cold boot

## WSL fixes in this release

- install `kmod`
- create `/etc/modules`
- mask `getty@tty1.service`
- mask `tpm-udev.path`
- mask `tpm-udev.service`
- mask `systemd-binfmt.service`
- keep `kmod-static-nodes.service` available

## Install

```powershell
wsl --install --from-file .\Pop_OS-24.04-WSL-Base-0.1.1-x86_64.wsl
```

Then:

```powershell
wsl -d Pop_OS-24.04
```

Complete the first-run OOBE and verify:

```bash
pop-wsl doctor
```

Expected final status:

```text
Failed units:          0
Status:                READY
```
